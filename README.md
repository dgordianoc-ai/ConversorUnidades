# Conversor de Unidades

Programa de consola desarrollado en C# que permite realizar conversiones de unidades mediante un menú interactivo.

## Funciones

- Celsius a Fahrenheit.
- Fahrenheit a Celsius.
- Kilómetros a Millas.
- Millas a Kilómetros.
- Validación de datos mediante `TryParse`.
- Manejo de opciones no válidas.
- Menú repetitivo utilizando `do-while`.
- Uso de métodos `private` para cada conversión.

## Ejecución

Para ejecutar el proyecto desde la terminal:

```bash
dotnet run
